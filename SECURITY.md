# Security policy

**Status:** Evaluation-only MVP (v0.1). The public repository is not an assurance of production security review.

Report sensitive issues privately to the repository owner. Do not share real AD names, group rosters, screenshots, or directory snapshots in public GitHub issues. Use synthetic reproduction data.

The collector uses read-only AD operations. The local reports are sensitive evidence in real environments. Verify scope, permissions, and controls before use.
